# Workflow catalog

One directory per workflow. `tool.yml` holds the TRS tool, tool class and
version metadata; every file listed under `files:` is read from the same
directory and uploaded as the version's file wrapper. Select workflows per
instance with `spe_workflows`.

`gatk-hc-chr20/main.nf` is the last version (v17) exported from the live TRS
on spe-ga4gh-api-2 on 2026-10-08.
